## 차근차근 주차 연습

p5.js 기반의 키보드 주차 시뮬레이션입니다. 로컬 웹 서버에서 `index.html`을 열어 실행합니다.

- ↑: 전진, ↓: 브레이크 및 후진
- ← / →: 조향 (움직이는 동안 작동)
- Space: 정지, R 또는 다시 시작 버튼: 초기화
- 초록색 주차 구역 안에 차체 전체를 넣고 주차선과 나란하게 1초간 정차하면 성공합니다.
- 장애물과 외벽에 부딪히면 정지하며 충돌 횟수가 표시됩니다.

기존 위치·속도·가속도 구조에 조향, 마찰, 회전 사각형 충돌 검사를 추가했습니다. 표시 속도는 게임용 환산값입니다. 키보드가 있는 환경을 권장합니다.
